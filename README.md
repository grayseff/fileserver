# Fileserver

A minimal HTTP fileserver written in C for FreeBSD

A personal project to learn UNIX networking, HTTP, file handling, HTML and HTTP parsing as well as network security principles.

Currently under development, serves HTML files on localhost. No capsicum framework, not deployed anywhere meaningful.
