Small server.
Real HTTP.

A deliberately minimal HTTP fileserver written in C and running on FreeBSD. This page is a practical test of static-file routing, HTTP headers, and multi-chunk buffered transmission.

How a request gets served

01
accept()

Accept an incoming TCP connection.

02
read()

Read the HTTP request line into a fixed-size buffer.

03
route()

Parse the method and path; choose a response status.

04
openat()

Open the requested resource relative to the files directory.

05
snprintf()

Build the HTTP status line and response headers.

06
write()

Send the headers and stream the body in chunks.

07
close()

Release the descriptors and await the next client.
